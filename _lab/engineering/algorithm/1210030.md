## 문제

일직선으로 뻗은 산책로에 가로등을 세울 수 있는 자리가 N곳 있다. 각 자리는 산책로의 시작점에서부터의 거리(좌표)로 나타내며, 자리마다 좌표가 모두 다르다.

이 중 C개의 자리를 골라 가로등을 설치하려 한다. 가로등끼리 너무 가까이 있으면 비효율적이므로, 가장 가까운 두 가로등 사이의 거리가 최대가 되도록 자리를 고르고 싶다.

N곳의 좌표와 설치할 가로등 수 C가 주어질 때, 가장 가까운 두 가로등 사이 거리의 최댓값을 구한다.

- 설치 가능한 자리 수 N(3 ≤ N ≤ 200,000), 설치할 가로등 수 C(2 ≤ C ≤ N)
- 좌표는 0 이상 1,000,000,000 이하의 정수이고, 모두 서로 다르다
- 입력: 첫 줄에 N과 C, 둘째 줄에 N곳의 좌표
- 출력: 가장 가까운 두 가로등 사이 거리의 최댓값

```
입력
5 3
2 15 6 20 9

출력
7
```

좌표를 정렬하면 `2, 6, 9, 15, 20`이다. 2번 자리에 첫 가로등을 세우고, 다음은 2에서 7 이상 떨어진 자리 중 가장 가까운 9(6은 2에서 4밖에 안 떨어져 있어 제외), 그 다음은 9에서 7 이상 떨어진 자리 중 가장 가까운 20(15는 9에서 6밖에 안 떨어져 있어 제외)에 세우면 2, 9, 20 이렇게 3개를 세울 수 있다. 거리를 8로 늘리면 2, 15 두 개만 세울 수 있어 C=3을 만족하지 못한다.

## 공통 코드

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int c = sc.nextInt();
        int[] spots = new int[n];
        for (int i = 0; i < n; i++) spots[i] = sc.nextInt();

        System.out.println(maxMinDistance(c, spots)); // 로직은 각 시도 참고
    }
}
```

## 시도 1 — 최소 간격을 이분 검색으로 찾기 (성공, 채택)

### 접근

좌표를 오름차순으로 정렬한다. 가장 가까운 두 가로등 사이 거리(후보 `mid`)를 하나 정했을 때, 그 거리 이상씩 떨어뜨리며 최대한 많은 가로등을 세워보면(`placeCount`) 몇 개까지 세울 수 있는지 알 수 있다. 그 개수가 C개 이상이면 이 거리는 가능하니 더 큰 거리도 되는지 보고, C개보다 적게 세워진다면 거리가 너무 커서 불가능하니 거리를 줄인다.

```java
import java.util.Arrays;

public static int maxMinDistance(int c, int[] spots) {
    int answer = 0;

    Arrays.sort(spots);

    int lt = 1;
    int rt = spots[spots.length - 1] - spots[0];

    while (lt <= rt) {
        int mid = (lt + rt) / 2;
        if (placeCount(spots, mid) >= c) {
            answer = mid;
            lt = mid + 1;
        } else {
            rt = mid - 1;
        }
    }
    return answer;
}

public static int placeCount(int[] spots, int distance) {
    int count = 1;
    int last = spots[0];
    for (int i = 1; i < spots.length; i++) {
        if (spots[i] - last >= distance) {
            last = spots[i];
            count++;
        }
    }
    return count;
}
```

### 결과

**성공** — 예제에서 `7` 출력.

복잡도: 시간 O(N log D)(D는 좌표의 최대-최소 차이. `placeCount`가 배열을 한 번 훑어 O(N)이고, 이분 검색 범위를 좁히는 데 O(log D)번 반복한다), 공간 O(1)(정렬은 배열 안에서 이뤄진다). 실제로 자리 20만 곳 중 10만 개를 배치해봐도 30ms 안팎이다.

### 분석

이 문제도 이전 글([이사 트럭의 최소 적재량 구하기](/lab/engineering/algorithm/1210029/))처럼 결정 알고리즘을 쓴다 — 답이 있다고 가정하고, 가능한 답의 범위를 추린 다음, 그 범위 안에서 답을 이진 검색으로 줄여나가면서 후보가 유효한지 판단하기를 반복한다. 단계는 똑같지만 방향이 정반대다.

1. **답이 있다고 가정한다.** "C개의 가로등을 세울 수 있는, 가장 가까운 두 가로등 사이의 최대 거리가 어딘가에 존재한다"고 가정한다.
2. **가능한 답의 범위를 추린다.** 거리는 최소 1(좌표가 모두 달라서 거리 0은 의미가 없다)부터, 최대 "가장 먼 두 좌표 사이의 거리"(그보다 더 멀리 떨어뜨릴 필요는 없다)까지로 좁힌다.
3. **그 범위 안에서 답을 이진 검색으로 줄여 나간다.** 범위의 가운데 값(`mid`)을 지금 확인해볼 거리 후보로 고른다.
4. **그 후보가 유효한지 판단하기를 반복한다.** "이 거리(`mid`) 이상 간격을 두고 세우면 가로등을 C개 이상 세울 수 있는가?"를 확인해서, 유효하면(C개 이상 세울 수 있으면) 더 큰 거리도 되는지 보려고 범위를 오른쪽으로, 유효하지 않으면(C개를 못 채우면) 거리를 줄여야 하니 범위를 왼쪽으로 좁힌다.

이전 글(이사 트럭)과 나란히 보면 3~4단계의 방향이 반대라는 게 드러난다. 트럭 문제는 적재량을 키울수록 필요한 트럭 수가 줄어드는 관계였고, 조건을 만족하면(트럭 M대 이하) **더 작은 값**을 찾으려 했다(`rt = mid - 1`). 이 문제는 거리를 키울수록 세울 수 있는 가로등 수가 줄어드는 관계고, 조건을 만족하면(C개 이상) **더 큰 값**을 찾으려 한다(`lt = mid + 1`). "조건을 만족하는 값들이 한쪽으로 쏠려 있다"는 단조성은 똑같이 필요하지만, 그 조건을 만족하는 값이 작은 쪽에 몰려 있는지 큰 쪽에 몰려 있는지에 따라 이분 검색이 좁히는 방향이 달라진다 — 이걸 헷갈리면 `lt`/`rt`를 반대로 옮겨 엉뚱한 값을 찾게 된다.

`placeCount`가 그 "예/아니오 판단"을 맡는다. 좌표를 순서대로 보면서, 마지막으로 세운 가로등(`last`)으로부터 거리가 `distance` 이상 떨어진 자리를 만나면 그 자리에 가로등을 세운다(`count++`, `last` 갱신). 다 보고 난 뒤 센 개수가 C개 이상이면 이 거리로 충분히 C개를 세울 수 있다는 뜻이다.

## 정리

| 시도 | 핵심 | 복잡도 | 결과 |
|---|---|---|---|
| **1. 결정 알고리즘(이분 검색) (채택)** | 거리 범위를 좁히며 "C개 이상 세울 수 있는가"를 반복 질문 | O(N log D) | 정답 |

**채택: 시도 1.** 거리처럼 최대 10억에 가까운 값을 하나하나 다 시도해볼 수 없는 범위에서, 결정 알고리즘은 `log D`번의 예/아니오 질문만으로 답을 찾는다.

- 결정 알고리즘에서는 "조건을 만족하는 값이 찾는 값보다 작은 쪽에 몰려 있는가, 큰 쪽에 몰려 있는가"를 먼저 파악해야 한다. 작은 쪽(많을수록 불리한 값을 최소화하는 경우)이면 조건을 만족할 때 범위를 왼쪽으로, 큰 쪽(많을수록 유리한 값을 최대화하는 경우)이면 조건을 만족할 때 범위를 오른쪽으로 좁힌다 — [이사 트럭의 최소 적재량 구하기](/lab/engineering/algorithm/1210029/)와 이 글을 나란히 보면 그 차이가 드러난다.
- "최댓값을 최소화"하는 문제와 "최솟값을 최대화"하는 문제는 언뜻 반대로 보이지만, 둘 다 "예/아니오로 답할 수 있는 조건에 단조성이 있다"는 같은 구조를 공유한다. 어떤 문제를 이분 검색으로 풀 수 있는지 판단할 때는, 구체적으로 무엇을 최소화하는지 최대화하는지보다 이 단조성이 있는지를 먼저 본다.
