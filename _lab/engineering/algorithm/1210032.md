## 문제

디지털 자물쇠는 사용자가 입력한 10진수 비밀번호를 2진수로 변환해 LED에 순서대로 표시한다(가장 높은 자리부터 순서대로 켜진다).

10진수 N이 입력되면 2진수로 변환해 출력하는 프로그램을 작성한다. 단 재귀 함수를 이용해서 출력해야 한다.

- N(1 ≤ N ≤ 1,000)
- 입력: 첫 줄에 10진수 N
- 출력: 2진수로 변환한 결과

```
입력
22

출력
10110
```

> 출처: 인프런 [자바(Java) 알고리즘 문제풀이 입문: 코딩테스트 대비](https://www.inflearn.com/course/자바-알고리즘-문제풀이-코테대비)의 재귀 단원 문제를 소재와 예제만 바꿔 재구성했다.

## 공통 코드

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();

        printBinary(n); // 로직은 각 시도 참고
    }
}
```

## 시도 1 — 재귀 호출 뒤에 나머지 출력하기 (성공, 채택)

### 접근

n을 2로 나눈 몫(`n / 2`)으로 먼저 재귀 호출을 하고, 그 호출이 다 끝나고 돌아온 뒤에 지금 자리의 나머지(`n % 2`)를 출력한다.

```java
public static void printBinary(int n) {
    if (n == 0) return;
    printBinary(n / 2);
    System.out.printf("%d", n % 2);
}
```

### 결과

**성공** — N=22를 넣으면 `10110`이 출력된다.

복잡도: 시간 O(log N)(n을 2로 나누는 횟수만큼만 재귀 호출한다), 공간 O(log N)(재귀 호출이 쌓이는 깊이).

### 분석

10진수를 2진수로 바꾸는 가장 흔한 방법은 "2로 나눈 나머지를 구하고, 몫으로 같은 일을 반복한 뒤, 나온 나머지들을 거꾸로 읽는다"이다. 손으로 계산할 때는 나머지를 하나씩 적어두었다가 마지막에 거꾸로 읽지만, 재귀 함수는 그 "거꾸로 읽기"를 **함수가 되돌아오는 순서**로 대신한다. `n / 2`로 내려가는 호출을 다 마치고 나서야(몫이 0이 되어 더 나눌 수 없을 때부터 거슬러 올라오면서) 나머지를 출력하므로, 가장 나중에 구해진 나머지(최상위 자리)가 가장 먼저 출력된다.

이전 글([엘리베이터 점검 안내 순서대로 방송하기](/lab/engineering/algorithm/1210031/))에서 재귀 호출 뒤에 출력을 두면 "되돌아오는 순서"대로 출력된다고 본 것과 같은 원리다. 만약 재귀 호출 **앞**에 출력을 뒀다면, 나머지가 구해지는 순서(최하위 자리부터) 그대로 출력돼 자릿수가 거꾸로 나왔을 것이다.

## 정리

| 시도 | 핵심 | 복잡도 | 결과 |
|---|---|---|---|
| **1. 재귀 호출 뒤에 나머지 출력 (채택)** | 되돌아오는 순서로 최상위 자리부터 출력 | O(log N) | 정답 |

**채택: 시도 1.** 2진수 변환은 나머지가 최하위 자리부터 구해지지만 출력은 최상위 자리부터 해야 한다 — 이 순서 반전을 재귀 호출 뒤에 출력을 두는 것만으로 해결한다.

- 값을 구하는 순서와 출력해야 하는 순서가 반대일 때, 재귀 호출 앞뒤 중 어디에 할 일을 두느냐로 그 반전을 처리할 수 있다. 따로 배열에 모았다가 거꾸로 도는 것보다 간단하다.
- 10진수를 다른 진법으로 바꾸는 문제는 전부 이 틀을 따른다 — 나누는 수(진법)만 2에서 8이나 16 등으로 바꾸면 그대로 적용된다.
