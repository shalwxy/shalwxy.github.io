## 문제

복도에 로봇 청소기가 있다. 로봇은 한 번 움직일 때 앞으로 1칸, 뒤로 1칸, 또는 앞으로 5칸 중 하나를 선택해 이동할 수 있다. 로봇의 현재 위치 S에서 목표 위치 E까지 가는 데 필요한 최소 이동 횟수를 구한다.

- 복도의 위치는 1부터 10,000까지의 좌표로 나타낸다
- 입력: 첫 줄에 로봇의 현재 위치 S와 목표 위치 E
- 출력: 목표 위치까지 가는 데 필요한 최소 이동 횟수(답은 1 이상이며 반드시 존재한다)

```
입력
5 14

출력
3
```

```
입력
8 3

출력
5
```

> 출처: 인프런 [자바(Java) 알고리즘 문제풀이 입문: 코딩테스트 대비](https://www.inflearn.com/course/자바-알고리즘-문제풀이-코테대비)의 재귀 단원 문제를 소재만 바꿔 재구성했다.

## 공통 코드

```java
import java.util.LinkedList;
import java.util.Queue;
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int s = sc.nextInt();
        int e = sc.nextInt();
        int[] moves = {1, -1, 5};
        int max = 10000;

        System.out.println(minMoves(moves, s, e, max)); // 로직은 시도 참고
    }
}
```

## 시도 1 — BFS로 가까운 위치부터 넓혀가며 찾기 (성공, 채택)

### 접근

현재 위치에서 한 번 이동으로 갈 수 있는 모든 위치를 큐에 넣고, 이동 횟수(레벨)별로 넓혀가며 탐색한다. 목표 위치를 처음 만나는 순간의 레벨이 곧 최소 이동 횟수다.

```java
public static int minMoves(int[] moves, int s, int e, int max) {
    boolean[] visited = new boolean[max];
    Queue<Integer> queue = new LinkedList<>();
    queue.offer(s);
    visited[s - 1] = true;

    int level = 0;
    while (!queue.isEmpty()) {
        int size = queue.size();
        for (int i = 0; i < size; i++) {
            int x = queue.poll();
            if (x == e) return level;
            for (int move : moves) {
                int next = x + move;
                if (next >= 1 && next <= max && !visited[next - 1]) {
                    visited[next - 1] = true;
                    queue.offer(next);
                }
            }
        }
        level++;
    }
    return -1;
}
```

### 결과

**성공** — S=5, E=14면 `3`, S=8, E=3이면 `5`가 출력된다.

복잡도: 시간 O(max)(좌표마다 최대 한 번씩 큐에 들어가고, 들어갈 때마다 이동 가짓수(3개)만큼 확인한다), 공간 O(max)(방문 배열과 큐).

### 분석

어떤 위치를 큐에 처음 넣는 순간의 레벨이 바로 그 위치까지의 최소 이동 횟수다 — BFS는 가까운 레벨을 전부 다 보고 나서야 다음 레벨로 넘어가므로, 목표 위치를 "처음" 만났다는 것은 "더 적은 이동 횟수로는 도달할 수 없었다"는 뜻과 같다. 한 번 방문한 위치는 다시 큐에 넣지 않는데(`visited` 배열), 같은 위치를 또 방문해봐야 그보다 짧은 경로는 이미 지나간 레벨에서 찾았을 것이기 때문이다.

이동 방법이 "앞으로 1, 뒤로 1, 앞으로 5"처럼 뒤섞여 있어서, 단순히 "가장 큰 폭(5칸)으로만 움직이면 빠르다"는 식으로 직접 계산하기 어렵다 — 뒤로 가는 선택지가 있다는 것 자체가, 때로는 돌아갔다가 다시 전진하는 쪽이 더 짧을 수도 있다는 뜻이다(S=8, E=3처럼 목표가 더 작은 쪽에 있을 때가 그렇다). 이렇게 다음 상태가 여러 갈래로 갈리고 그중 최단 경로를 찾아야 하는 문제는, 가능한 모든 경우를 가까운 것부터 고르게 넓혀가는 BFS가 자연스럽게 들어맞는다.

## 정리

| 시도 | 핵심 | 복잡도 | 결과 |
|---|---|---|---|
| **1. BFS로 레벨별 탐색 (채택)** | 처음 도달한 레벨이 곧 최소 이동 횟수 | O(max) | 정답 |

**채택: 시도 1.** 이동 방법이 여러 가지이고 뒤로 가는 선택지까지 있어 직접 계산이 어려운 "최단 이동 횟수" 문제는, 가능한 위치를 가까운 것부터 넓혀가는 BFS로 접근하는 게 가장 안전하다.

- "최소 횟수"나 "최단 거리"를 구하는 문제에서 다음 상태로 가는 방법이 여러 가지이고 되돌아가는 것도 가능할 때는, 공식으로 직접 계산하기보다 BFS로 가능한 상태를 레벨별로 넓혀가며 찾는 편이 안전하다. 처음 도달한 레벨이 항상 최솟값이기 때문이다.
- `visited` 배열로 이미 와본 위치를 막아두지 않으면, 1칸 앞으로 갔다가 1칸 뒤로 오는 식으로 큐가 무한히 불어날 수 있다. 상태 공간(여기서는 좌표)을 탐색할 때는 항상 "이미 방문한 상태를 어떻게 표시할지"를 먼저 정해야 한다.
