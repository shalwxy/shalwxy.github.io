## 문제

엘리베이터 점검 기사가 N층짜리 건물의 꼭대기(N층)에서 출발해, 한 층씩 내려가며 점검한다. 더 내려갈 데가 없는 지점(1층 아래)에 닿으면, 그제서야 내려온 순서를 거슬러 올라오면서 각 층의 점검 완료 안내를 방송한다.

자연수 N이 입력되면, 재귀 함수를 이용해 1층부터 N층까지 점검 완료 안내를 순서대로 출력하는 프로그램을 작성한다.

- N(3 ≤ N ≤ 10)
- 입력: 첫 줄에 N
- 출력: 1부터 N까지 공백으로 구분해 한 줄에 출력

```
입력
6

출력
1 2 3 4 5 6
```

> 출처: 인프런 [자바(Java) 알고리즘 문제풀이 입문: 코딩테스트 대비](https://www.inflearn.com/course/자바-알고리즘-문제풀이-코테대비)의 재귀 단원 문제를 소재와 예제만 바꿔 재구성했다.

## 공통 코드

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();

        printInOrder(n); // 로직은 각 시도 참고
    }
}
```

## 시도 1 — 먼저 출력하고 재귀 호출하기 (실패)

### 접근

지금 층(`n`)을 먼저 출력하고, 그다음에 한 층 아래(`n-1`)로 내려가는 재귀 호출을 한다.

```java
public static void printInOrder(int n) {
    if (n == 0) return;
    System.out.printf("%d ", n);
    printInOrder(n - 1);
}
```

### 결과

**실패** — N=6을 넣으면 `6 5 4 3 2 1`이 출력된다. 1부터 6까지 순서대로 나와야 하는데, 거꾸로(내림차순) 나온다.

### 분석

출력을 재귀 호출보다 **먼저** 하면, 가장 큰 값(`n`)이 가장 먼저 출력되고, 그다음 호출에서 더 작은 값들이 차례로 출력된다 — 호출되는 순서 그대로가 출력 순서가 된다. "내려가면서" 바로바로 안내 방송을 내보내는 셈이라, 꼭대기 층부터 거꾸로 방송되는 것과 같다. 1층부터 순서대로 나오게 하려면, 출력을 **맨 밑에 닿은 뒤 돌아오는 길**에 해야 한다.

## 시도 2 — 재귀 호출부터 하고 나중에 출력하기 (성공, 채택)

### 접근

한 층 아래(`n-1`)로 내려가는 재귀 호출을 먼저 하고, 그 호출이 전부 끝나고 돌아온 뒤에야 지금 층(`n`)을 출력한다.

```java
public static void printInOrder(int n) {
    if (n == 0) return;
    printInOrder(n - 1);
    System.out.printf("%d ", n);
}
```

### 결과

**성공** — N=6을 넣으면 `1 2 3 4 5 6`이 출력된다.

복잡도: 시간 O(N), 공간 O(N)(재귀 호출이 쌓이는 깊이만큼 스택을 쓴다).

### 분석

`printInOrder(n - 1)`이 먼저 실행되고, 그 안에서 또 `printInOrder(n - 2)`가 먼저 실행되고… 이렇게 `n`이 0이 될 때까지 호출만 계속 쌓인다(그림의 왼쪽 열). `n`이 0에 닿으면(`if (n == 0) return;`) 더 내려갈 곳이 없으니 그 호출은 즉시 끝나고, 바로 위에서 기다리고 있던 `printInOrder(1)` 호출로 돌아온다. 거기서 멈춰 있던 `System.out.printf("%d ", n)`이 이제야 실행되어 1을 출력하고, 그 호출이 끝나 다시 한 단계 위(`printInOrder(2)`)로 돌아가 2를 출력하고… 이 과정이 반복되며 1, 2, 3, …, n 순서로 출력된다(그림의 오른쪽 열).

즉 호출이 내려가는 순서(3, 2, 1)와 출력이 일어나는 순서(1, 2, 3)는 서로 반대다 — 출력을 재귀 호출 **뒤에** 적어두면, 그 줄은 "맨 밑까지 다녀온 뒤에" 실행되기 때문이다.

## 정리

| 시도 | 핵심 | 결과 |
|---|---|---|
| 1. 출력 → 재귀 호출 | 호출 순서 그대로 출력됨(내림차순) | 실패 |
| **2. 재귀 호출 → 출력 (채택)** | 되돌아오는 순서대로 출력됨(오름차순) | 정답 |

**채택: 시도 2.** 1부터 N까지 오름차순으로 출력해야 하는데, 재귀 호출 뒤에 출력을 적어야 그 순서가 나온다.

- 재귀 함수 안에서 **"무엇을 먼저 하느냐"가 실행 순서를 결정한다.** 재귀 호출 앞에 적은 코드는 "내려가는 길"에 실행되고, 재귀 호출 뒤에 적은 코드는 "돌아오는 길"에 실행된다.
- 재귀로 순서를 뒤집고 싶을 때(예: 내림차순을 오름차순으로), 반복문처럼 조건이나 증감식을 바꾸는 대신 **출력을 재귀 호출 앞에 두느냐 뒤에 두느냐**만 바꿔도 된다.
