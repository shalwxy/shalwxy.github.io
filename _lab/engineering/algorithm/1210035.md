## 문제

아래와 같이 번호가 매겨진 조직도가 있다. 각 사람 아래로 최대 두 명의 직속 부하가 연결된다.

{% include figure image_path="/assets/img/lab/org-chart-binary-tree.svg" alt="7명이 삼각형 모양으로 배치된 조직도. 맨 위 1 아래로 2와 3이, 2 아래로 4와 5가, 3 아래로 6과 7이 선으로 연결된다" caption="연습에 쓸 조직도. 1이 최상위이고, 각 사람 아래로 최대 두 명이 연결된다" %}

이 조직도를 아래 세 가지 순서로 순회하며 사람 번호를 출력한다.

- 전위 순회(preorder): 자신을 먼저 방문하고, 왼쪽 부하 → 오른쪽 부하 순서로 내려간다
- 중위 순회(inorder): 왼쪽 부하를 먼저 방문하고, 자신 → 오른쪽 부하 순서로 방문한다
- 후위 순회(postorder): 왼쪽 부하와 오른쪽 부하를 모두 방문한 뒤, 마지막에 자신을 방문한다

```
출력
전위 순회: 1 2 4 5 3 6 7
중위 순회: 4 2 5 1 6 3 7
후위 순회: 4 5 2 6 7 3 1
```

> 출처: 인프런 [자바(Java) 알고리즘 문제풀이 입문: 코딩테스트 대비](https://www.inflearn.com/course/자바-알고리즘-문제풀이-코테대비)의 재귀 단원 연습문제를 소재만 바꿔 재구성했다.

## 공통 코드

아래 세 순회는 모두 같은 조직도(`Node` 트리)를 입력으로 받는다. 각 순회에서는 방문하는 메서드(`preOrder`, `inOrder`, `postOrder`)만 다르다.

```java
class Node {
    int val;
    Node left;
    Node right;

    Node(int val) {
        this.val = val;
    }
}

public class Main {
    public static Node root;

    public static void main(String[] args) {
        root = new Node(1);
        root.left = new Node(2);
        root.right = new Node(3);
        root.left.left = new Node(4);
        root.left.right = new Node(5);
        root.right.left = new Node(6);
        root.right.right = new Node(7);

        System.out.print("전위 순회: ");
        preOrder(root);
        System.out.println();

        System.out.print("중위 순회: ");
        inOrder(root);
        System.out.println();

        System.out.print("후위 순회: ");
        postOrder(root);
        System.out.println();
    }
}
```

## 전위 순회(Preorder) — 자신 → 왼쪽 → 오른쪽

### 접근

노드를 만나면 그 자리에서 바로 자신의 번호를 출력하고, 그다음 왼쪽으로, 그다음 오른쪽으로 내려간다.

```java
public static void preOrder(Node root) {
    if (root == null) return;
    System.out.printf("%d ", root.val);
    preOrder(root.left);
    preOrder(root.right);
}
```

### 결과

**성공** — `1 2 4 5 3 6 7` 출력.

### 분석

출력이 재귀 호출보다 **먼저** 있어서, 노드에 처음 도착하는 순간 바로 번호가 찍힌다. 그래서 출력 순서가 "위에서 아래로, 왼쪽 먼저" 내려가는 순서와 그대로 같다 — 맨 위(1)가 가장 먼저, 왼쪽 갈래(2, 4, 5)를 다 보고서야 오른쪽 갈래(3, 6, 7)로 넘어간다.

## 중위 순회(Inorder) — 왼쪽 → 자신 → 오른쪽

### 접근

왼쪽을 전부 순회하고 돌아온 뒤에야 자신을 출력하고, 그다음 오른쪽으로 내려간다.

```java
public static void inOrder(Node root) {
    if (root == null) return;
    inOrder(root.left);
    System.out.printf("%d ", root.val);
    inOrder(root.right);
}
```

### 결과

**성공** — `4 2 5 1 6 3 7` 출력.

### 분석

출력이 두 번의 재귀 호출 **사이**에 있다. 왼쪽 갈래를 끝까지 다 보고 돌아올 때까지는 자신을 출력하지 않으므로, 각 노드는 "자기 왼쪽 부분을 전부 다녀온 다음"에야 등장한다. 이 순서가 의미를 가지려면 보통 "왼쪽에 작은 값, 오른쪽에 큰 값"을 넣어두는 이진 탐색 트리처럼 노드 배치에 규칙이 있어야 한다 — 지금 조직도는 번호가 그런 규칙 없이 매겨져 있어서, 중위 순회 결과(`4 2 5 1 6 3 7`) 자체는 오름차순 같은 특별한 의미를 갖지 않는다.

## 후위 순회(Postorder) — 왼쪽 → 오른쪽 → 자신

### 접근

왼쪽과 오른쪽을 모두 순회하고 돌아온 뒤에야 마지막으로 자신을 출력한다.

```java
public static void postOrder(Node root) {
    if (root == null) return;
    postOrder(root.left);
    postOrder(root.right);
    System.out.printf("%d ", root.val);
}
```

### 결과

**성공** — `4 5 2 6 7 3 1` 출력.

### 분석

출력이 두 번의 재귀 호출보다 **뒤**에 있어서, 자신의 부하(왼쪽, 오른쪽)를 전부 방문하고 되돌아온 뒤에야 자신이 출력된다. 그래서 맨 위(1, 조직도의 최상위)가 가장 마지막에 나온다 — "부하를 다 처리한 뒤에 보고를 마무리하는" 순서와 같다. 자식을 먼저 정리해야 자신을 처리할 수 있는 상황(예: 폴더를 지울 때 하위 파일부터 지워야 하는 경우)에 이 순서를 쓴다.

## 정리

세 순회는 모두 "왼쪽을 보고 오른쪽을 본다"는 틀은 같고, **자신을 언제 출력하느냐**만 다르다.

| 순회 | 자신을 출력하는 시점 | 결과 |
|---|---|---|
| 전위(Preorder) | 맨 처음(왼쪽을 보러 가기 전) | `1 2 4 5 3 6 7` |
| 중위(Inorder) | 중간(왼쪽을 다 본 뒤, 오른쪽을 보기 전) | `4 2 5 1 6 3 7` |
| 후위(Postorder) | 맨 마지막(왼쪽, 오른쪽을 다 본 뒤) | `4 5 2 6 7 3 1` |

- 전위 순회는 자신부터 먼저 알아야 하위로 내려갈 수 있는 상황(예: 폴더 구조를 위에서부터 출력하기)에 맞는다.
- 중위 순회는 왼쪽에 작은 값, 오른쪽에 큰 값을 두는 이진 탐색 트리에서 값을 오름차순으로 꺼낼 때 쓴다.
- 후위 순회는 하위를 다 처리해야 자신을 처리할 수 있는 상황(예: 폴더를 삭제할 때 하위 파일부터 지우기, 트리 구조의 수식을 계산할 때 피연산자부터 계산하기)에 맞는다.
