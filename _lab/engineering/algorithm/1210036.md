## 문제

피자 가게에는 N가지 토핑이 있다(1번부터 N번까지 번호가 매겨져 있다). 손님이 고를 수 있는 토핑 조합을 모두 나열한다(토핑을 하나도 고르지 않는 경우는 제외한다).

자연수 N이 주어지면 1부터 N까지의 토핑 번호로 만들 수 있는 모든 조합을 출력하는 프로그램을 작성한다.

- N(1 ≤ N ≤ 10)
- 입력: 첫 줄에 자연수 N
- 출력: 한 줄에 하나씩, 아래 출력 예제와 같은 순서로 조합을 출력한다. 공집합(아무것도 안 고른 경우)은 출력하지 않는다.

```
입력
4

출력
1 2 3 4
1 2 3
1 2 4
1 2
1 3 4
1 3
1 4
1
2 3 4
2 3
2 4
2
3 4
3
4
```

## 공통 코드

```java
import java.util.Scanner;

public class Main {
    public static int n;
    public static int[] picked;

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        n = sc.nextInt();
        picked = new int[n];

        listCombos(1); // 로직은 시도 참고
    }
}
```

## 시도 1 — 고르거나 안 고르거나, 두 갈래로 나눠 끝까지 내려가기 (성공, 채택)

### 접근

1번 토핑부터 N번 토핑까지 순서대로 "이 토핑을 고른다"와 "고르지 않는다"를 각각 재귀로 시도한다. N번째 토핑까지 결정을 다 마치면(`l == n + 1`), 그때까지 고른 토핑들을 모아 한 줄로 출력한다.

```java
public static void listCombos(int l) {
    if (l == n + 1) {
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < picked.length; i++) {
            if (picked[i] == 1) {
                sb.append(i + 1).append(' ');
            }
        }
        if (sb.length() > 0) {
            System.out.println(sb.toString().trim());
        }
        return;
    }

    picked[l - 1] = 1;
    listCombos(l + 1);

    picked[l - 1] = 0;
    listCombos(l + 1);
}
```

### 결과

**성공** — N=4를 넣으면 위 예제와 같은 순서로 15줄이 출력된다.

복잡도: 시간 O(N × 2^N)(가능한 조합이 2^N − 1가지이고, 조합마다 토핑 번호를 모아 출력하는 데 최대 O(N)), 공간 O(N)(재귀 호출 깊이와 `picked` 배열).

### 분석

`listCombos(l)`은 l번째 토핑을 고를지 말지 두 갈래로 갈라진다 — 먼저 `picked[l - 1] = 1`로 놓고 그 토핑을 고른 채로 더 깊이 들어가고, 그 가지가 끝까지 다 끝나고 돌아오면 이번엔 `picked[l - 1] = 0`으로 바꿔서 그 토핑을 안 고른 채로 다시 깊이 들어간다. 매 토핑마다 두 갈래로 갈라지는 걸 N번 반복하면, 가능한 모든 "고름/안 고름" 조합(2^N가지)이 전부 한 번씩 나온다.

출력 순서가 "1번을 고른 가지를 전부 먼저 끝내고 나서야 1번을 안 고른 가지로 넘어간다"는 식으로 정해지는 이유도 여기에 있다 — `picked[l - 1] = 1`로 두고 들어가는 호출이 먼저 적혀 있어서, 그 안에서 벌어지는 모든 조합이 전부 출력된 뒤에야 `picked[l - 1] = 0`인 가지로 넘어간다.

## 정리

| 시도 | 핵심 | 복잡도 | 결과 |
|---|---|---|---|
| **1. 고르거나 안 고르거나 (채택)** | 토핑마다 포함/제외 두 갈래로 재귀 | O(N × 2^N) | 정답 |

**채택: 시도 1.** 포함/제외라는 단순한 두 갈래 재귀만으로 모든 조합을 빠짐없이, 요구된 순서 그대로 나열할 수 있다.

- "각 원소를 포함할지 말지"를 하나씩 정해나가는 재귀는, 원소가 N개면 자동으로 2^N가지 조합을 전부 만들어낸다 — 조합의 개수를 따로 세거나 반복문을 몇 겹으로 겹칠지 고민할 필요가 없다.
- 재귀 안에서 두 갈래(포함 먼저, 제외 나중)를 적는 **순서**가 곧 출력되는 **순서**를 결정한다. 포함하는 가지를 먼저 적었으므로, 그 가지에서 나오는 조합들이 전부 먼저 출력된다.
