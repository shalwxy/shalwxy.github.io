## 문제

사진 동아리에서 단체 사진을 찍을 때, N명이 한 줄로 서는 방법은 모두 몇 가지인지 구한다(순서만 달라도 다른 배치로 센다).

자연수 N이 입력되면 N명이 한 줄로 설 수 있는 경우의 수를 구하는 프로그램을 작성한다. 예를 들어 5명이면 5×4×3×2×1 = 120가지다.

- N(1 ≤ N ≤ 10)
- 입력: 첫 줄에 자연수 N
- 출력: N명이 한 줄로 설 수 있는 경우의 수

```
입력
6

출력
720
```

> 출처: 인프런 [자바(Java) 알고리즘 문제풀이 입문: 코딩테스트 대비](https://www.inflearn.com/course/자바-알고리즘-문제풀이-코테대비)의 재귀 단원 문제를 소재와 예제만 바꿔 재구성했다.

## 공통 코드

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();

        System.out.println(countLineups(n)); // 로직은 각 시도 참고
    }
}
```

## 시도 1 — 나머지 인원의 경우의 수에 곱하기 (성공, 채택)

### 접근

N명이 설 수 있는 경우의 수는 "맨 앞에 설 한 명을 고르고, 나머지 N-1명이 한 줄로 서는 경우의 수를 곱한 것"과 같다. "나머지가 한 줄로 서는 경우의 수"를 구하는 일 자체가 크기만 작아진 같은 문제이므로, 재귀로 그대로 표현할 수 있다. 1명만 남았을 때는 설 수 있는 방법이 1가지뿐이므로, 그게 재귀의 끝(기저 조건)이다.

```java
public static int countLineups(int n) {
    if (n == 1) return 1;
    return n * countLineups(n - 1);
}
```

### 결과

**성공** — N=6을 넣으면 `720`이 출력된다.

복잡도: 시간 O(N)(재귀 호출이 N번 일어난다), 공간 O(N)(재귀 호출이 쌓이는 깊이).

### 분석

`countLineups(n)`은 "맨 앞 한 자리를 채우는 n가지 선택"과 "나머지 n-1명을 줄 세우는 경우의 수"를 곱한다. 나머지를 줄 세우는 경우의 수도 같은 방식으로 정의되므로, 결국 n × (n-1) × (n-2) × … × 1을 계산하게 된다 — 이게 N!의 정의 그대로다. n이 1까지 내려가면(남은 한 명을 세우는 방법은 1가지뿐이니) 더 곱할 게 없어 재귀가 멈춘다.

## 정리

| 시도 | 핵심 | 복잡도 | 결과 |
|---|---|---|---|
| **1. n × (n-1)명의 경우의 수 (채택)** | 맨 앞 한 자리 선택 × 나머지의 경우의 수 | O(N) | 정답 |

**채택: 시도 1.** N!의 정의(N × (N-1)!) 자체가 "자기보다 하나 작은 같은 문제의 답에 N을 곱한다"는 재귀 구조이므로, 코드도 그 정의를 그대로 옮기면 된다.

- "크기가 하나 작은 같은 문제의 답을 안다면 지금 문제도 풀 수 있다"는 관계가 보이면, 그 관계를 그대로 재귀 함수의 점화식으로 옮길 수 있다 — N! = N × (N-1)!이 그 예다.
- 기저 조건(여기서는 n == 1)을 "더 이상 곱할 대상이 없는 가장 작은 경우"로 정하면, 그 지점에서 반환하는 값(1)이 자연스럽게 정의와 맞아떨어진다.
