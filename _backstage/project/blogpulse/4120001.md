## 1. 배경 및 목적

개인 블로그나 웹페이지를 운영하려면 유입 경로, 페이지별 이탈과 이동 흐름, 댓글·좋아요 같은 사용자 반응을 제때 파악해 콘텐츠나 화면을 개선하고 독자 피드백에 빠르게 대응해야 한다. 기존 웹 분석 도구를 붙이면 기본 통계는 볼 수 있지만, **원천 데이터를 직접 제어하거나, 새 댓글·조회수 돌파 순간에 내 폰으로 알림을 받거나, 장애로 누락된 알림을 대시보드에서 다시 처리하는(Replay) 흐름**까지는 만들기 어렵다.

그래서 **"어느 웹페이지든 스크립트 한 줄만 붙이면 방문자 흐름과 반응을 모아 대시보드로 보여주고, 주요 이벤트는 핸드폰으로 바로 알려주는 서비스"**를 직접 구축하기로 했다.

### 핵심 목표
* **범용성:** 특정 블로그 플랫폼에 종속되지 않고, 일반 웹페이지와 개인 블로그 어디든 스크립트(`tracker.js`) 한 줄로 연동할 수 있어야 한다.
* **능동형 알림:** 대시보드를 일부러 열어보지 않아도 새 댓글, 좋아요, 조회수 마일스톤 달성 시 모바일 메신저로 즉시 알림을 받는다.
* **실시간성 및 운영 편의:** 방문자 지표를 실시간으로 확인하고, 알림 발송 실패 건이 생겨도 원인을 확인해 원클릭으로 재발송할 수 있어야 한다.

## 2. 수집 대상 및 핵심 기능 요구사항

### 2.1 사용자 행동 및 반응 수집

| 수집 항목 | 발생 시점 | 활용 목적 |
| :--- | :--- | :--- |
| **페이지 조회 (`page_view`)** | 방문자가 페이지에 진입할 때 | 일간/누적 조회수(PV), 순 방문자(UV), 인기 페이지 순위 산출 |
| **페이지 이탈 (`page_leave`)** | 탭을 닫거나 다른 화면으로 전환할 때 | 페이지별 실제 체류 시간, 최대 스크롤 깊이(완독률) 측정 |
| **외부 링크 클릭 (`outbound_click`)** | 페이지 내 외부 도메인 링크를 클릭할 때 | 추천 링크·참고 자료 클릭 전환율 확인 |
| **좋아요/반응 (`reaction_created`)** | 좋아요 버튼 클릭 또는 임베드 위젯 반응 증가 시 | 글별 반응 밀도 집계 및 즉시 모바일 푸시 알림 트리거 |
| **댓글 등록 (`comment_created`)** | 댓글 폼 등록 또는 임베드 위젯 댓글 수 증가 시 | 즉시 모바일 푸시 알림 트리거 |

### 2.2 분석 및 대시보드 화면 구성
1. **오버뷰 (트래픽 & 반응 요약)**
   * 현재 동시 접속자 수, 일간/누적 조회수, 댓글·좋아요 합계
   * 인기 페이지 랭킹 및 **모바일 / 데스크톱 기기별 필터링·비교**
2. **유입 · 이탈 · 방문자 여정 분석**
   * **유입 채널 분석:** 검색 유입, SNS/커뮤니티, 직접 유입(`Direct`), UTM 파라미터별 유입 비중
   * **이탈률 및 완독률:** 첫 페이지에서 바로 나간 비율(Bounce Rate), 기기별 평균 체류 시간 및 스크롤 깊이 비교
   * **다음에 읽은 페이지 (`Next-Read Flow`):** A 페이지를 읽은 방문자가 다음으로 가장 많이 이동한 B 페이지 순위
3. **파이프라인 상태 & 장애 복구 뷰**
   * 초당 수집 요청 수, 봇/중복 차단 건수, 알림 발송 성공/실패 현황
   * **실패한 알림 목록 조회 및 원클릭 재전송(Replay) 버튼**

### 2.3 모바일 푸시 알림 정책
* **즉시 알림:** 새 댓글 또는 좋아요 반응이 발생하면 지체 없이 모바일 채널(Telegram, Slack, Discord, ntfy 중 선택)로 알림을 발송한다.
* **마일스톤 알림:** 특정 페이지 누적 조회수가 설정 임계치(`100`, `500`, `1,000` 등)를 최초 돌파할 때 1회 축하 알림을 발송한다.

## 3. 3주 구현 일정

| 주차 | 마일스톤 | 주요 산출물 |
| :--- | :--- | :--- |
| **1주차** | 코어 수집 파이프라인 구축 | 모노레포 및 로컬/VM 컨테이너 환경, 이벤트 수집 API, DB 배치 적재 워커 |
| **2주차** | 여정 분석 · 알림 · 조회 API | 유입·이탈·기기별·Next-Read 집계, 모바일 푸시 알림 및 재시도/DLQ, 대시보드 조회 API·SSE |
| **3주차** | 추적 SDK · 대시보드 · 검증 | 웹페이지 삽입용 `tracker.js`, 대시보드 UI 3종, 부하 테스트 및 장애 복구 검증 결과 |
